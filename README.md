# Hyper-cycle - E-Waste & Hazardous Battery Disposal Network

Hyper-cycle is a responsive, multi-page website that helps households and small businesses find e-waste disposal centres, request doorstep pickups, and calculate eco-credits for recyclable electronics and hazardous batteries.

## Features

- **Home:** E-waste categories, battery safety tips, and recycling guidelines.
- **Drop-Off Locator:** Search and filter sample recycling centres.
- **Pickup Booking:** Validated form with booking reference generation.
- **Credit Calculator:** Calculate eco-credits based on item type, age, condition, and quantity.
- **About & Contact:** Project information, FAQs, and contact form.
- **Responsive Design:** Works across mobile, tablet, and desktop screens.

## Getting Started

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or build tools are required.

## Limitations

- Recycling centres and voucher details use sample data.
- No backend is connected; bookings and contact messages are not stored.
